# Rechtliche Unterlagen – ENTWÜRFE

> **Status: Entwurf zur rechtlichen Prüfung.** Diese Unterlagen beschreiben, was die Plattform technisch tut. Sie ersetzen keine Rechtsberatung. Vor der Verwendung gegenüber Kunden prüft eine Rechtsanwältin oder ein Rechtsanwalt bzw. die Datenschutzberatung von ME-IT die Texte und passt sie an (insbesondere österreichisches DSG, Branchenvorgaben, Haftung).

| Dokument                                                   | Zweck                                                           |
| ---------------------------------------------------------- | --------------------------------------------------------------- |
| [AVV-VORLAGE.md](AVV-VORLAGE.md)                           | Auftragsverarbeitungsvertrag nach Art. 28 DSGVO (ME-IT ↔ Kunde) |
| [TOM.md](TOM.md)                                           | Technische und organisatorische Maßnahmen nach Art. 32 DSGVO    |
| [UNTERAUFTRAGSVERARBEITER.md](UNTERAUFTRAGSVERARBEITER.md) | Liste der Unterauftragsverarbeiter                              |
| [LOESCHKONZEPT.md](LOESCHKONZEPT.md)                       | Welche Daten wann gelöscht werden                               |

In der App selbst (Einstellungen → Datenschutz) finden Kunden: Aufbewahrungsfristen, Datenauskunft und Löschung pro Person, das Verzeichnis von Verarbeitungstätigkeiten als Vorlage und die Unterauftragsverarbeiter dieser Installation. Pro Agent gibt es einen Steckbrief (EU-KI-Verordnung).
